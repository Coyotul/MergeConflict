## Bugs found in earlier tasks while building the sets (please check)

- **Task 3 `canonical_key`:** the rule "dated filename → parent folder" merges different documents that share a folder. One instance: `documents/pf/in-sprijinul-tau/` holds 3 dated PDFs (card notice, call-center notice, 2017 credit-conditions notice). Suggested fix: use the folder only when it holds a single dated file. Otherwise use folder + filename without the date prefix and suffix.
- **Task 3 `fee_list_sections`:** the fee list's numbering appears to restart at "1." within each part (both "1. Conturi curente…" and "1. Operațiuni de încasări…" occur). So the number → topic map mislabels sections. Example: credit-card interest and fees were tagged `accounts` in the mock chunking (chunk 22 of the fee list), so a default credit-topic search would hide them. Key the map on part + number, or on heading keywords.
- **Cost sheets:**
  - Raiffeisen's Casa Ta 5-year cost sheet contains the 3-year figures; its filename even says "3 ani". The real 5-year figures appear only on the product page.
  - Generic row rebuilding scrambles the word order of the Flexi Integral 5-year sheet. This confirms the template parser is needed.
- **Pages that disagree** (the conflict notice won't catch these, because they are cross-kind):
  - pre-approval validity: 45 vs 90 days
  - minimum income for a personal loan: 510 EUR vs the minimum net wage
  - mortgage down payment: 15–25% vs 15–35%
